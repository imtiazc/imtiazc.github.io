I architected the high-performance SaaS backend for **Cisco WebEx Social** (Spring, Oracle, MongoDB, Memcached) and drove end-to-end performance work through query tuning and service redesign.

## From on-prem to stateless

I led the migration of a legacy on-premises application to a **service-oriented, stateless cloud architecture** that achieved **zero downtime during rolling upgrades**. I also built core backend services, including RBAC for API endpoints and product analytics.

## Standards work

Earlier, I led feature development for Cisco Transport Manager and represented Cisco in **Tele-Management Forum (TMF)** standards work with AT&T, Verizon, and Sprint. Some of those proposals were adopted into global telecom practice.
